## Rule 7: The criminal-code cross-reference is updated

Collection: sgi. Comparison: Prior law to amended law. Type: Wording. Actor/class: Intermediaries. Earlier context: Prior Rule 7, updated 22 Oct 2025.

Status: Notified amendment; operative-date and court-status limits apply.

### Textual observation

Rule 7's Indian Penal Code reference is replaced with the Bharatiya Nyaya Sanhita citation. [Prior Rule 7, updated 22 Oct 2025](https://www.meity.gov.in/static/uploads/2025/10/708f6a344c74249c2e1bbb6890342f80.pdf) [Final amendment 5; Gazette p. 12](https://www.meity.gov.in/static/uploads/2026/02/f55fe52418b03f58b0669f6a8bc03b6d.pdf)

Earlier excerpt (PRIOR CONSOLIDATED RULE, as extracted):

> including the provisions of the Act and the Indian Penal Code

Later excerpt (NOTIFIED AMENDMENT, as printed, as extracted):

> “the Bharatiya Nyaya Sanhita, 2023 (45 of 2023)”

### Analyst interpretation

This updates the named criminal-law reference; it is not evidence that every breach automatically creates criminal guilt.
