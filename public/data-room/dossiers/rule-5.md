Collection: dpdp. Comparison: Draft to final. Type: Wording. Actor/class: State bodies. Earlier context: Rule 5.

### Analyst interpretation

The enabling sentence is removed from the rule, not the parent statute. Read section 7(b) and the Second Schedule together.

### Limits and follow-up

Do not infer unrestricted state processing from a shortened rule.

Reporting question: Which legal basis and processing standards apply to a named public service?

Parent statute context: [DPDP Act](https://www.meity.gov.in/static/uploads/2024/06/2bf1f0e9f04e6fb4f8fef35e82c42aa5.pdf). Read statutory limits as well as the rule.
