# UPSC face authentication: implementation and procurement evidence

Checked 2026-10-05. Existing registry family `sys-upsc`; baseline values unchanged.

## What changes

Tender retention/SOP provisions are not silently applied to the later mobile application. Scale and timing are official claims, not recognition-accuracy evidence.

A continuity link from the 2024 procurement to the 2026 app, successful bidder/contract, mismatch SOP, denial statistics and face-specific appeal handling were not established.

### Implementation

Primary records reviewed; strength/stage varies. Next record: Dated acceptance, commissioning, training-completion or go-live records for the named scope.

The proposed service includes Aadhaar-based fingerprint authentication or digital fingerprint capture, facial recognition, e-Admit Card QR-code scanning, and live AI-based CCTV surveillance. The tender further specifies that facial recognition should use a stateless transaction comparing a registration image with an image captured on exam day. ([Tender responses invited from PSUs for Aadhaar-based candidate authentication, QR-code scanning and live AI-based CCTV surveillance](https://upsc.gov.in/sites/default/files/Tender-AadhaarQRFaceRecgAI-engl-250624.pdf)).

Strength: Formal prescribed requirement; type: Requirement / specification; event date: Not established. Independent outcome verification: no.

Page 9, section 6.1.9. [Original text](https://upsc.gov.in/sites/default/files/Tender-AadhaarQRFaceRecgAI-engl-250624.pdf).
