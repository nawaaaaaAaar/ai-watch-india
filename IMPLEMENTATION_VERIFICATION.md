## Reproduction

```sh
npm ci
python scripts/build_expansion.py
python scripts/build_implementation.py
node scripts/package-briefs.mjs
npm run validate:data
npm test
npm run build
```

Builders consume the included source snapshots, preserve exact normalized quotations and verify their membership. Hashes establish integrity of extracted text, not original PDF binaries or bilingual legal accuracy; OCR and Markdown extraction artefacts remain visible.

## Research and deployment boundaries

The primary constitution instruments and official announcements establish documentary actions, not that meetings, recommendations or resulting work were completed. Recruitment is not appointment; a call is not a contract; approval is not proven efficacy; a commitment is not verified compliance.

“Implementation not established by reviewed records” is deliberately bounded. Search is not exhaustive, and missing documentation does not prove nonexistence. No agency confirmation, interview, information request, independent legal review, model evaluation or user-validation study was conducted.

No paid services or public launch were undertaken. Existing privacy boundaries remain: imported notebooks and review notes are session-local, and external model calls are absent. The static preview and source repository are updated without provisioning a production backend.
