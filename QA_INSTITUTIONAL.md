# AI Watch: institutional-release QA inventory

This inventory covers release 1.1.0. It is a test plan, not a claim of completed checks.

## Claims and critical workflows

- Dataset: 36 systems, 32 institutions, 70 sources, 432 accountability assertions and 21 linked tables. Check generated metadata, SQLite, JSON, CSV, dossier counts and the displayed release version.
- Institutional frame: six named institutions, 26 associated systems and ten earlier context records outside the frame. Exercise each selector and reset; inspect desktop and mobile filtered states.
- Research evidence: open all 36 system routes and verify all twelve dimensions. Inspect source details, uncertainty, BODH infrastructure, CCTNS timeline conflict, the CROPIC declaration tension and channel-specific Bharat-VISTAAR observations.
- Source review: verify fifty baseline source receipts and 216 source-availability assertion triages. Preserve the distinction between fresh and cached matches and never label this independent recoding.
- Reuse: download the complete archive, SQLite, JSON, new research study, four new table CSVs and filtered CSV through actual browser clicks; compare downloaded bytes to generated files. Exercise all table download controls.
- Reproduction: clean checkout, deterministic package rebuild, automated tests, production build and foreign-key checks.
- Regression: supporting policy routes, old corrections and notebook export remain accessible. Automated historical-corpus invariance tests supplement browser checks.

## Visual coverage

Inspect explorer, filtered explorer, institutional data room and a new system dossier at desktop and 375-pixel mobile widths. Check settled light and dark themes, long institution labels, horizontally scrolling tables, expanded evidence, unknown-field labels, initial heading and action visibility, and absence of document-level horizontal overflow.

## Off-happy paths and exploration

- No-results search and reset, unknown system identifier, failed dataset request and successful retry.
- A CSV request returning HTML must show an error rather than produce a misleading download.
- Explore combined frame/AI filters, sorting, switching to supporting policy evidence, expanding several evidence records and downloading an individual dossier.

## Reporting boundaries

Browser and automated checks validate release integrity and implemented behavior. They do not verify real-world system effectiveness, national completeness, independent review or user demand. Retain any failed checks and their resolution in the verification report.
